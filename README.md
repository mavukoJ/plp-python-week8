# Week 8 Final Project: Personal Mini-Toolkit

## About My Project

My Personal Mini-Toolkit is a simple Python program that brings three useful tools together in one menu. It includes a simple calculator, a to-do list manager, and an even-or-odd number checker. The user can select a tool, use it, and return to the main menu.

## How to Run the Program

1. Install Python on your computer if it is not already installed.
2. Open a terminal in the folder containing `toolkit.py`.
3. Run the command `python toolkit.py`.
4. Choose a tool from the menu and follow the instructions.
5. Choose option 4 to quit the program.

## What I Learned

While working on this project, I learned how to bring different Python concepts together in one program. The hardest part was making the menu return after each tool finished. The part that took the longest to fix was handling invalid choices and preventing errors when users entered incorrect information. I also learned how to use lists to add, view, and remove tasks. I tested the tools to make sure they worked as expected. If I had one more week, I would add a feature to save my tasks so they would still be available when I opened the program again.
